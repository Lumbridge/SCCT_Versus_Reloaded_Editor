# Clarity Soft (ClarD)

Recovered editable source and playable map for Chaos Theory Versus.

Copy the `Packages` folder into your game's root directory, merging the folders:

- `Packages/MapsEd/ClarD_Recovered_4.sdc` — editable source; open it normally in Reloaded Editor.
- `Packages/Maps/ClarD_Recovered_4.sdc` — playable map.
- `Packages/StaticMeshes/ClarD_Recovered_4_Assets.usx` — required by both maps.

Keep these filenames together so the maps can find their asset package. The
original game's textures, sounds and other shared assets are also required.

Recovered on 13 September 2026 with 1,254 structural brushes, 5,167 retained
actors, six procedural soft bodies and 3,029 preserved mesh colour streams.
